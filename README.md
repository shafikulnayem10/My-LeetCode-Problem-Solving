## 📖 About This Repository

This repository is my personal record of solving [LeetCode](https://leetcode.com/) problems. I solve problems regularly and push each solution here to track my progress and keep a public log of my learning.

The goals behind it:

- Strengthen **problem-solving** and **algorithmic thinking**
- Build a solid understanding of **data structures and algorithms (DSA)**
- Write **clean, efficient code** and learn to reason about time and space complexity
- Practice in more than one language, depending on the problem and what I'm learning

Most solution files start with the problem statement as comments, followed by the solution and a few test calls, so each file is readable on its own.









## 🌱 Motivation

Progress in problem solving comes from consistency more than from any single big session. Each problem teaches a pattern, and patterns carry over to the next problem. Revisiting old solutions, finding cleaner approaches, and learning from mistakes is how the skills build up over time.

This repository is a record of that practice, and I plan to keep adding to it.
